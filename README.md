# Scam Sense AI

Scam Sense AI is a multi-modal scam detection web app that helps users identify suspicious links, messages, images, QR codes, and audio content using AI.

## Features

- Detects phishing or scam-like URLs
- Analyzes suspicious SMS, WhatsApp messages, and emails
- Scans uploaded images and screenshots
- Extracts and checks QR code links
- Analyzes audio for possible scam or vishing patterns
- Provides simple multilingual safety explanations
- Includes a community threat ledger for scam reports
- Uses rate limiting to protect API endpoints

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Gemini AI
- Google Safe Browsing API
- Firebase Firestore
- Upstash Redis
- jsQR
